# Oliveira Bank 🏦

Projeto de sistema bancário desenvolvido em Python durante meus estudos de programação Backend.

**Funcionalidades atuais**

- Depósito de valores
- Saque de valores
- Validação de saldo insuficiente
- Bloqueio de saques negativos ou iguais a zero
- Consulta do saldo final

**Tecnologias**
- Python

**Objetivo**
- Desenvolver minhas habilidades em lógica de programação, estruturas condicionais e construção de sistemas, evoluindo o projeto gradualmente.

**Próximas melhorias**
- Menu interativo
- Múltiplas operações
- Funções
- Histórico de transações

**Como executar**
- Execute o arquivo main.py com Python instalado.
